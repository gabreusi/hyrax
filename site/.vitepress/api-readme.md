# API reference

Every export of the three entrypoints, generated from the TSDoc in the source, so it always matches the code. The
examples on these pages are checked like the ones in the guides: the core ones are run and their `// =>` results
asserted, and the `/dom` and `/react` ones are type-checked.

Looking for how and why rather than what? Each entrypoint has a guide, starting at
